# 🎾 Bouncing Ball Animation

A simple and responsive bouncing ball animation built using **HTML**, **CSS**, and **Bootstrap**. This project demonstrates basic animation principles and layout styling with Bootstrap utilities.

## 📁 Project Structure


/bouncing-ball-animation ├── index.html ├── style.css └── README.md

## 🛠 Technologies Used

- **HTML5** – Structure of the page
- **CSS3** – Animation and styling
- **Bootstrap 5** – Layout and responsiveness

## 🎨 Features

- Smooth vertical bouncing animation
- Responsive layout using Bootstrap grid
- Customizable ball size, color, and bounce speed

## 📦 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/bouncing-ball-animation.git


- Open index.html in your browser.
- To deploy on GitHub Pages:
- Push to your GitHub repo
- Go to Settings → Pages
- Set source to main branch and root folder
🧩 CustomizationYou can tweak the animation by editing style.css:@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-150px); }
}
Change the translateY value to adjust bounce height.
